# 모두의 원정대 (ModuQuest)

서로 다른 감각과 인지 방식을 가진 플레이어들이 하나의 파티로 함께 모험하는
접근성 우선 RPG.

**▶ [브라우저에서 바로 플레이](https://moduquest.com/)** — 설치 없이 링크만 열면 된다.

> 시험 운영 중이다. 혼자 하기는 로그인 없이 즐길 수 있고, 함께 하기(최대 3인)에만
> 계정이 필요하다. 계정과 기록이 예고 없이 초기화될 수 있다 —
> [이용약관](https://moduquest.com/terms.html) ·
> [개인정보처리방침](https://moduquest.com/privacy.html)

대부분의 "접근성 있는 게임"은 완성된 게임에 옵션을 덧붙인 형태다. 이 프로젝트는 반대로,
함께 플레이하는 것 자체를 설계의 출발점에 두었다. 시각장애인은 소리와 스크린리더로,
청각장애인은 자막과 시각 신호로, ADHD·자폐 스펙트럼 플레이어는 단순한 목표와 조작으로
즐긴다. 각자 다른 인터페이스를 쓰지만 같은 전투, 같은 이야기를 공유한다.

## 같은 게임, 세 개의 렌즈

그림·글·소리 세 갈래로 같은 상황을 동시에 내보낸다. 하나만 써도 게임이 온전히
돌아가고, 겹쳐 쓰면 더 풍부해진다.

- **그림** — 픽셀 그래픽과 캐릭터의 움직임
- **글** — 스크린리더 낭독, 그리고 화면에 쌓이는 텍스트 기록. 옛 통신망 텍스트 게임처럼
  글만 읽어도 게임을 따라갈 수 있다
- **소리** — 합성 효과음과 방향이 있는 공간 음향. 어느 쪽이 벽인지 소리로 알 수 있다

텍스트 기록은 원래 시각장애인을 위한 낭독 문장이었는데, 화면에 흘려 보니 누구에게나
재미있는 기능이 됐다. 그래서 기본으로 켜 둔다.

## 게임 방법

세 스테이지를 지나면 끝난다. 한 스테이지는 5~20분이고 뒤로 갈수록 길다.

조용해진 숲에서 돌 골렘을 물리치면 골렘 안에서 종소리가 난다. 소리를 따라 어두운 굴을
지나 탑에 오르면, 종지기가 큰 종을 울려 주변을 모두 같은 박자로 맞추고 있다. 숲이 조용했던
이유다. 파티는 각자 다르게 느끼기 때문에 그 박자에 맞춰지지 않는다.

시작할 때 전사·도적·궁수·마법사·힐러 다섯 직업에서 나와 동료 둘을 고른다. 동료들은
스스로 판단해서 함께 싸운다. 필드를 칸 단위로 돌아다니다 몹과 마주치면 턴제 전투가
벌어진다. 몹은 화면에 보이므로 피해 갈 수도 있다. 전투에서 지더라도 잃는 것은 없다.
쉼터에서 모두 회복한 채 다시 시작한다.

스테이지는 여러 구역으로 나뉘어 있고, 문을 밟으면 다음 구역으로 건너간다. 마지막
스테이지에는 갈림길이 있어 종지기에게 곧장 갈 수도, 돌아가며 보물을 챙길 수도 있다.
지도 모양은 저장 자리마다·다시 시작할 때마다 달라지는데 무작위가 아니라 순서다 —
같은 기록을 불러오면 언제나 같은 지도가 나온다.

전투에서는 공격·스킬·도구·방어 중 하나를 고른다. 데미지에 무작위 요소가 없어서 결과를
미리 알 수 있고, 시간 제한도 없다. 기술은 마력을 쓰고, 라운드가 끝날 때마다 정해진 양이
돌아온다. 이기면 정해진 경험치가 쌓여 파티가 함께 강해지고, 3레벨이 되면 직업마다
두 번째 기술이 열린다.

몹도 아무나 치지 않는다. 하급은 앞에 선 사람을, 중급은 가장 많이 다친 사람을, 보스는
방어가 얇은 사람을 노린다. 전사의 도발은 그 위에 있어서, 누구를 노리던 적이든 전사에게
끌어온다.

아이템에도 확률이 없다. 같은 몹을 잡을 때마다 정해진 순서로 드랍이 나오고 — 슬라임은
세 번째마다 작은 물약 — 보물상자는 밟으면 열리며 내용이 고정이다. 보스는 처음 잡으면
정해진 보상을 반드시 주고, 다시 잡으면 좋은 장비 칸이 더 많은 순환을 탄다.

장비는 무기·갑옷·신발·장갑 네 자리다. 상태창에서 입고 벗으면 능력치와 함께 캐릭터의
겉모습도 바뀌고, 능력치는 "공격 21 (기본 18 + 장비 2 + 동료 1)"처럼 출처를 밝힌다.
울림 세트를 모으면 보너스가 붙고, 깃발·등불 같은 장비는 든 사람이 아니라 곁의 동료를
강하게 한다. 규칙은 게임 안 도움말에 전부 밝혀 두었다 — 숨기면 정보 격차지만 밝히면
전략이 되기 때문이다.

타이틀 화면에서 **특성**을 고르면 플레이 방식이 달라진다. 속도를 얻고 공격을 내주는
"날렵한 걸음", 상대 방어를 뚫는 대신 느려지는 "정확한 손", 가까운 곳만 알 수 있지만
빠르고 잘 흘리는 "좁은 지각" 같은 것들이다. 이득과 대가가 항상 함께 붙어 있고 숫자로
전부 밝혀져 있다.

## 함께 하기

혼자 하던 모험 그대로, 셋까지 한 파티가 되어 같은 세계를 걷는다. 타이틀의
**멀티 플레이**에서 로그인하고 모험단을 만들면 여덟 글자 초대 코드가 나오고, 동료는
그 코드로 들어온다. 혼자 시작해도 동료는 나중에 그 코드로 합류할 수 있다.
**싱글 플레이**는 지금까지처럼 로그인 없이 그대로다.

무작위가 없는 게임이라 가능한 방식이다 — 모두의 화면이 같은 명령을 같은 순서로
재생하면 전투의 피해도, 상자의 내용물도, 지도 모양도 전원에게 똑같다. 이동과 대화
넘김은 **길잡이** 한 사람이 쥔다. 넘겨주며 걷는 이 규칙은 제일 느린 사람의 속도를
파티의 속도로 만든다. 전투는 각자 자기 차례에 자기 행동을 고른다.

연결이 끊긴 자리는 동료 AI가 즉시 이어받아 파티가 멈추지 않고, 다시 접속하면 같은
자리로 돌아온다. 전리품은 파티의 것이고 저장은 각자 자기 계정의 자리에 똑같이 된다 —
함께 하던 모험을 이후에 혼자 이어서 해도 된다. 세션 밖에서는 **선물함**으로 친구
코드를 아는 상대에게 물건을 보낼 수 있다.

기록이 어디에 남는지는 어느 문으로 들어왔는지가 정한다. **싱글 플레이**는 가입 없이
바로 시작하고 이 기기에만 남는다. **멀티 플레이**는 로그인하면 계정에 남아 다른
기기에서도 이어서 할 수 있고, 친구와 함께 걸어도 혼자 걸어도 된다. 두 벌은 서로 다른
세 칸이라 섞이지 않는다.

## 조작

| | 키보드 | 화면 버튼 |
|---|---|---|
| 이동 | 화살표 키 또는 WASD | 방향 버튼 |
| 주변 확인 | R | 둘러보기 |
| 선택·확정 | Enter 또는 Space | 클릭·터치 |
| 옵션 (일시정지) | ESC | 옵션 |
| 타이틀로 나가기 | ESC → 타이틀로 나가기 | 옵션 → 타이틀로 나가기 |

전 기능을 키보드만으로 쓸 수 있고, 키보드 없이 화면 버튼만으로도 쓸 수 있다.
휴대폰에서도 그대로 동작한다.

## 접근성 기능

- 스크린리더 낭독 — 모든 상황이 문장으로 전달된다
- 텍스트 기록 — 지나간 상황을 글로 되짚을 수 있다
- 효과음 자막 — `[타격]` 형식으로 소리를 시각화한다
- 공간 음향 — 방향이 있는 소리는 헤드폰에서 좌우·전후로 들린다
- 저자극 모드 — 움직임과 깜빡임을 끄고 채도·음량을 낮춘다. OS의 "동작 줄이기" 설정을
  기본값으로 존중한다
- 큰 글씨, 소리 크기 조절
- 언제든 일시정지 — 옵션을 열면 게임이 멈춘다
- 특성 — 이득과 대가가 함께 붙은 플레이 스타일을 고른다. 어떤 특성을 골라도
  낭독·키보드·저자극 모드는 그대로 동작한다
- 저장 자리 세 칸 — 저장 버튼 없이 알아서 기록한다. 빈 자리는 새로 시작하고 기록이
  있는 자리는 이어서 하거나 지운다. 싱글 플레이는 이 기기에, 멀티 플레이는 계정에
  각각 세 칸씩 남는다. 클리어한 스테이지는 다시 갈 수 있다

## 직접 실행하기

Node.js 20 이상이 필요하다.

```bash
npm install
npm run dev
```

`http://localhost:5173/` 을 열면 된다. 그 밖의 명령:

```bash
npm test    # 게임 규칙 유닛 테스트
npm run build    # 정적 파일 빌드 (dist/)
```

## 기술

Phaser 4 + TypeScript + Vite로 만들었고 GitHub Pages에서 정적으로 돌아간다.

게임 규칙을 담은 `src/core`는 Phaser도 DOM도 모르는 순수 TypeScript다. 코어가 사건을
이벤트로 발행하면 그림(Phaser)·의미(DOM)·소리(Web Audio) 세 레이어가 각자 구독해
표현한다. 캔버스는 `aria-hidden`으로 감추고 메뉴와 전투 UI는 진짜 HTML로 만들어,
키보드 조작과 스크린리더 지원이 구조적으로 따라오게 했다.

능력치·스킬·지도·대사는 전부 `src/data`의 JSON이고, 스프라이트와 효과음은 파일이 아니라
코드로 생성한다.

## 현재 상태

세 스테이지 분량이고, 혼자서도 셋이서도 할 수 있다. 함께 하기는 실시간 채널 위에서
돌아가는데, 정적 호스팅이라 서버 권위가 없는 만큼 계정·선물·저장은 데이터베이스의
행 단위 권한이 지키고, 세션 안의 어긋남은 검증 합계로 감지해 방장의 기록으로
되맞춘다. 경쟁 요소가 없는 협동 전용이라 가능한 균형이다. 자세한 구조와 한계는
[구조 문서](docs/04-architecture.md)에 밝혀 두었다.
